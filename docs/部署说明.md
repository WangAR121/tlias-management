# 部署说明

项目分三部分：**MySQL 数据库** + **Spring Boot 后端（8080）** + **前端静态文件（nginx 90）**。
下面的命令都在仓库根目录执行。

## 一、构建后端

```bash
mvn clean package -DskipTests
```

产物：`target/tlias-web-management-0.0.1-SNAPSHOT.jar`

## 二、启动后端

```bash
# Linux / macOS
export DB_PASSWORD='你的数据库密码'
java -jar target/tlias-web-management-0.0.1-SNAPSHOT.jar --server.port=8080

# Windows PowerShell
$env:DB_PASSWORD = "你的数据库密码"
java -jar target/tlias-web-management-0.0.1-SNAPSHOT.jar --server.port=8080
```

看到 `Tomcat started on port 8080` 即成功。自检：

```bash
curl -X POST http://localhost:8080/login \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"admin\",\"password\":\"123456\"}"
```

返回 `{"code":1,...,"data":{"token":"..."}}` 说明数据库、后端都通了。

> Windows 用 PowerShell 时，带 JSON 的 curl 命令建议把请求体写进文件再用 `-d "@body.json"`，
> 否则引号容易被命令行吃掉。

## 三、部署前端（nginx）

1. 把 `frontend-dist/` 里的内容复制到 nginx 的 `html/` 目录（替换掉默认页）：

```
nginx/html/index.html
nginx/html/assets/...
```

2. 用 `deploy/nginx.conf.example` 覆盖 `conf/nginx.conf`（或在你的 server 块里照抄这段）：

```nginx
server {
    listen       90;
    server_name  localhost;
    client_max_body_size 10m;

    location / {
        root   html;
        index  index.html index.htm;
        try_files $uri $uri/ /index.html;      # 前端是单页应用，路由交给 index.html
    }

    location ^~ /api/ {
        rewrite ^/api/(.*)$ /$1 break;         # 去掉 /api 前缀
        proxy_pass http://localhost:8080;      # 转发给后端
    }
}
```

3. 启动 / 重载 nginx：

```bash
nginx -s reload        # 已经启动过
nginx                  # 或首次启动（Windows 下是 start nginx）
```

4. 浏览器访问 <http://localhost:90>，用 `admin / 123456` 登录。

## 四、前后端分离说明

- 前端所有请求都带 `/api` 前缀（axios 的 `baseURL` 是 `/api`），由 nginx 剥掉前缀后转发到后端。
- 后端接口本身**没有** `/api` 前缀。所以：
  - 通过 nginx 访问：`http://localhost:90/api/login`
  - 直连后端访问：`http://localhost:8080/login`
- 登录后前端把 JWT 放在 `localStorage.loginUser.token`，axios 请求拦截器自动加到请求头 `token`；
  后端 `tokenInterceptor` 校验失败返回 401，前端会自动跳回登录页。

## 五、前端源码二次开发（可选）

仓库里的 `frontend-dist/` 是编译产物。要改前端界面时：

```bash
npm install
npm run dev        # 本地开发，vite 默认 5173，需要在 vite.config.js 里把 /api 代理到 8080
npm run build      # 产物在 dist/，复制到 nginx 的 html/ 即可
```

## 六、部署常见问题

| 现象 | 排查 |
| --- | --- |
| 页面打开是白屏 | 静态文件没放对位置，或 `index.html` 里引用的 `/assets/...` 不存在 |
| 接口全部 404 | nginx 的 `/api/` 反代没配，或后端没启动 |
| 登录接口 200 但提示"出错了，联系管理员" | 后端抛异常了，看后端控制台 `程序出错了！` 的堆栈（常见：数据库没连上、表没建） |
| 所有接口 401 | 请求头没带 `token`，或 token 过期（默认 2 小时），重新登录 |
| 上传图片失败 | OSS 环境变量没配，或 Bucket 权限不对 |
