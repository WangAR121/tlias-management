# 操作说明

访问 <http://localhost:90>，用 `admin / 123456` 登录（账号来自 `db/tlias.sql` 的演示数据）。

## 1. 登录 / 退出

- 登录成功后，后端签发 JWT（有效期 2 小时），前端存在 `localStorage.loginUser` 里。
- 之后每个请求都会自动带上请求头 `token`；令牌过期或非法时后端返回 401，前端自动跳回登录页。
- 右上角头像 → **退出登录**：清除本地令牌并回到登录页。
  （注意：JWT 是无状态的，服务端 2 小时内仍认为该令牌有效；如需"立即失效"需要额外做令牌黑名单。）

## 2. 首页 / 报表

登录后进入首页，展示 4 个 ECharts 图表：

| 图表 | 含义 |
| --- | --- |
| 员工职位统计 | 各职位人数（柱状图，x 轴是职位名） |
| 员工性别统计 | 男/女占比（饼图） |
| 班级人数统计 | 每个班级的学员人数（柱状图，x 轴是班级名） |
| 学员学历统计 | 各学历人数占比（饼图） |

数据来自 `/report/empJobData`、`/report/empGenderData`、`/report/studentCountData`、`/report/studentDegreeData`。

## 3. 部门管理

- 列表：显示部门 id、名称、最后修改时间，按修改时间倒序。
- 新增 / 编辑：弹窗填写部门名称。⚠️ 名称最长 **10 个字符**（数据库是 `varchar(10)`），超长会报错。
- 删除：部门下**还有员工时不允许删除**，会提示"该部门有员工，无法直接删除"。

## 4. 员工管理

- 查询：支持按姓名、性别、入职时间区间筛选，分页展示。
- 新增：填写用户名、姓名、性别、手机号、职位、薪资、入职日期、所属部门，并可添加**多段工作经历**
  （公司、职位、起止时间）。头像可通过"上传"按钮传到阿里云 OSS。
- 编辑：回显后修改；工作经历可以增删改。
- 删除：列表勾选后批量删除。

## 5. 班级管理

- 查询：按班级名称、结课日期区间筛选，分页展示；列表带"状态"（未开班 / 在读中 / 已结课，由时间自动判断）。
- 新增 / 编辑：班级名、教室、班主任、学科、开课/结课时间。
- 删除：班级下**还有学员时不允许删除**。

## 6. 学员管理

- 查询：按姓名、学历、所属班级筛选，分页展示。
- 新增 / 编辑：学号、姓名、性别、手机号、学历、身份证号、所属班级、毕业时间等。
- 违纪处理：对某个学员记录违纪扣分（`PUT /students/violation/{id}/{score}`）。
- 删除：支持多个 id 批量删除。

## 7. 日志

- **操作日志**：`controller` 里标注了 `@Log` 注解的方法（各部门/员工/班级/学员的增删改）会被 AOP 切面
  记录到 `operate_log`：操作人、操作时间、类名、方法名、方法参数、返回值、耗时。
  失败的操作也会记录（返回值字段里是异常信息）。
  查询接口：`GET /log/page?page=1&pageSize=10`（需要 `token` 请求头）。
- **登录日志**：每次登录（成功或失败）都会写入 `emp_log`，记录时间与描述，例如
  `员工 管理员（admin）登录成功`、`账号 admin 登录失败：用户名或密码错误`。

## 8. 接口速查（后端直连 8080）

| 功能 | 方法 | 路径 |
| --- | --- | --- |
| 登录 | POST | `/login` |
| 部门列表/增删改 | GET/POST/PUT/DELETE | `/depts` |
| 员工分页/增删改 | GET/POST/PUT/DELETE | `/emps` |
| 班级分页/增删改 | GET/POST/PUT/DELETE | `/clazzs` |
| 学员分页/增删改 | GET/POST/PUT/DELETE | `/students` |
| 报表 | GET | `/report/empJobData`、`/report/empGenderData`、`/report/studentCountData`、`/report/studentDegreeData` |
| 文件上传 | POST | `/upload` |
| 操作日志分页 | GET | `/log/page` |

除 `/login` 外都需要请求头 `token`。
