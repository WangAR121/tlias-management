# 环境准备

## 1. 必需软件

| 软件 | 版本要求 | 说明 |
| --- | --- | --- |
| JDK | **21 及以上** | `pom.xml` 中 `java.version=21`，Spring Boot 4 需要 17+，本项目按 21 编译 |
| Maven | 3.8+ | 也可以用 IDEA 自带的 Maven |
| MySQL | 8.0 | 字符集 `utf8mb4` |
| nginx | 1.20+（可选） | 托管前端静态文件 + 反向代理后端 |
| Node.js | 16+（可选） | 只有要重新编译前端源码时才需要 |

> 只用后端 + 现成的前端静态文件时，**不需要** Node.js。

## 2. 检查环境

```bash
java -version          # 期望 21 或更高
mvn -v                 # 期望 3.8+
mysql --version        # 期望 8.0.x
```

## 3. 初始化数据库

1. 启动 MySQL 服务（Windows 可以在"服务"里启动 `MySQL80`）。
2. 执行建表脚本：

```bash
mysql -uroot -p < db/tlias.sql
```

脚本内容：
- 创建数据库 `tlias`（utf8mb4）
- 创建 7 张表：`dept`、`emp`、`emp_expr`、`clazz`、`student`、`operate_log`、`emp_log`
- 末尾插入了**演示数据**：1 个部门 + 1 个登录账号 `admin / 123456`（不需要可删掉该段）

执行完可以用下面的语句验证：

```sql
use tlias;
show tables;
select id, username, name from emp;
```

## 4. 配置环境变量

项目里所有敏感信息都通过环境变量注入，仓库不含任何密码。

| 变量名 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `DB_PASSWORD` | ✅ | 无 | 数据库密码 |
| `DB_USERNAME` | | `root` | 数据库账号 |
| `DB_HOST` | | `localhost` | 数据库地址 |
| `DB_PORT` | | `3306` | 数据库端口 |
| `DB_NAME` | | `tlias` | 数据库名 |
| `OSS_BUCKET_NAME` | 上传功能必填 | 无 | 阿里云 OSS Bucket |
| `OSS_ACCESS_KEY_ID` | 上传功能必填 | 无 | 阿里云 AccessKey ID |
| `OSS_ACCESS_KEY_SECRET` | 上传功能必填 | 无 | 阿里云 AccessKey Secret |
| `OSS_ENDPOINT` | | `https://oss-cn-beijing.aliyuncs.com` | OSS 接入点 |
| `OSS_REGION` | | `cn-beijing` | OSS 区域 |

**Windows（临时生效，当前命令行窗口）**

```powershell
$env:DB_PASSWORD = "你的数据库密码"
$env:OSS_BUCKET_NAME = "你的bucket"
$env:OSS_ACCESS_KEY_ID = "你的AccessKeyId"
$env:OSS_ACCESS_KEY_SECRET = "你的AccessKeySecret"
```

**IDEA 里运行**：`Run/Debug Configurations` → 选中启动类 → `Environment variables` 填
`DB_PASSWORD=你的密码;OSS_BUCKET_NAME=...;OSS_ACCESS_KEY_ID=...;OSS_ACCESS_KEY_SECRET=...`

**不想用环境变量**（仅限本地、且不要把改动提交）：在 `src/main/resources/` 下新建 `application-local.yml`
直接写配置，然后启动时加参数 `--spring.profiles.active=local`。该文件已被 `.gitignore` 忽略。

## 5. IDEA 导入

1. `File → Open`，选择本仓库根目录（有 `pom.xml` 的那一层），以 Maven 项目导入。
2. 等待依赖下载完成（首次较慢）。
3. 安装 **Lombok** 插件（`Settings → Plugins` 搜索 Lombok），并开启
   `Settings → Build → Compiler → Annotation Processors → Enable annotation processing`。
4. 运行 `heima.item.TliasWebManagementApplication`。

## 6. 常见问题

| 现象 | 原因 / 解决 |
| --- | --- |
| 启动报 `Could not resolve placeholder 'DB_PASSWORD'` | 没配环境变量，见第 4 节 |
| 启动报端口占用 `Port 8080 was already in use` | 换端口：`--server.port=8081`，或结束占用进程 |
| 控制台出现 `... is intercepting.` 的字符画 | PageHelper 分页插件的 banner，正常现象 |
| 编译报 Lombok 相关找不到 getter/setter | 没开注解处理，见第 5 节第 3 步 |
| 上传图片报 OSS 相关异常 | 没配 OSS 环境变量，见第 4 节 |
